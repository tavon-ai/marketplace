# Tavon Marketplace

A curated marketplace for Claude Code and Cowork plugins.

## Install

1. **Add the marketplace:**
   - Click **Customize** > **Browse Plugins** > **Personal**
   - Click **Add Marketplace from Github URL**
   - Enter: `https://github.com/tavon-ai/marketplace.git`

2. **Install a plugin:**
   - Browse the marketplace
   - Install `hello-world`

3. **Test it:**
   - Say: "hello marketplace"
