🚀 Quick Start

Add the marketplace in Claude Code or Cowork:

  1. Click Customize → Browse Plugins → Personal
  2. Click Add Marketplace from Github URL
  3. Enter the URL:
https://github.com/tavon-ai/marketplace.git

Then browse and install any plugin (try hello-world)
