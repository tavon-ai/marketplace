# Hello World Plugin

Example plugin demonstrating the basic structure of a Claude Code/Cowork plugin.

## Installation

1. Click **Customize** > **Browse Plugins** > **Personal**
2. Click **Add Marketplace from Github URL**
3. Enter: `https://github.com/tavon-ai/marketplace.git`
4. Browse and install `hello-world`

## Usage

Say: "hello marketplace"

Response:
```
👋 Hello from the Tavon Marketplace!

The hello-world plugin is working correctly. This simple skill demonstrates:
- How to structure a skill file
- When to activate a skill
- How to provide clear instructions to Claude
```

## Files

- `.claude-plugin/plugin.json` - Plugin metadata
- `skills/SKILL.md` - The hello-world skill definition
- `README.md` - This file
