# Landing Page Builder

Automated landing page creation for Webflow. Builds conversion-optimized pages with hero sections, feature showcases, and SEO metadata in under 5 minutes.

## What It Does

Transforms landing page creation from a 1-hour+ manual process into a streamlined 5-minute workflow by:

- Gathering all requirements upfront with structured prompts
- Building standard conversion-optimized layouts (hero + features + CTA)
- Applying SEO metadata and mobile responsiveness
- Following web design best practices automatically

## Use Cases

- Product landing pages
- Marketing campaign destinations  
- Service promotion pages
- Lead generation pages
- Event registration pages

## Prerequisites

- Webflow site created
- Webflow MCP server configured and connected
- Access to Webflow Designer

## Key Features

### 1. Structured Requirements Gathering
Uses `asktheuser` to collect complete information upfront:
- Business basics
- Hero section content
- 6 feature descriptions
- Social proof elements
- SEO metadata
- Design preferences

### 2. Standard Layout Structure
```
┌─ Hero Section (headline, subheadline, CTAs, image)
├─ Features Grid (6 features in responsive grid)
├─ Social Proof (optional testimonials, logos, stats)
├─ Final CTA Section
└─ Footer
```

### 3. Built-in Optimization
- SEO metadata (title, description, OG tags)
- Mobile responsive (3 breakpoints tested)
- Conversion best practices (CTAs above fold, clear value props)
- Performance optimization (image compression, loading speed)
- Accessibility (alt text, heading hierarchy)

### 4. Quality Checklist
Automated verification of:
- Content completeness
- SEO requirements
- Design consistency
- Mobile responsiveness
- Conversion elements

## How to Use

1. **Install the plugin** from the Tavon Marketplace

2. **Say:** "Build me a landing page for [your business]"

3. **Provide requirements** when prompted (the skill will ask for everything it needs)

4. **Review and publish** - Claude will build the page in Webflow
